## 📌 Project Overview
EduStream is a modern, comprehensive School Management System (SMS) designed to streamline academic operations. It provides dedicated interfaces for Students, Teachers, and Administrators, featuring real-time data visualization and AI-driven academic insights to enhance the educational experience.

## ✨ Features
- **Modern Dashboard UI:** Role-specific views with interactive charts and glassmorphism design.
- **AI Academic Advisor:** Integrated Google Gemini AI to provide personalized student feedback.
- **Role-Based Access:** Distinct modules for Admin, Teacher, and Student roles.
- **Performance Analytics:** Visual tracking of student progress using Recharts.
- **Responsive Design:** Optimized for mobile, tablet, and desktop viewing.
- **Demo Access Portal:** Easy-to-use testing credentials for presentation purposes.

## 🛠️ Technologies Used
- **Frontend Framework:** React 19 (TypeScript)
- **Bundler:** Vite
- **Styling:** Tailwind CSS
- **Charts:** Recharts
- **AI Engine:** Google Gemini API (@google/genai)

## 🚀 Deployment to Vercel
1. Push your code to GitHub.
2. Connect your GitHub repository to [Vercel](https://vercel.com).
3. In the Vercel **Project Settings**, go to **Environment Variables**.
4. Add `API_KEY` with your Google Gemini API Key as the value.
5. Click **Deploy**.
